# TERRA-SENTINEL

### Global Seismic Monitoring Platform

TERRA-SENTINEL is a free global scientific platform dedicated to earthquake monitoring, seismic data analysis, and interactive Earth visualization.

## Project Vision

To provide accessible and reliable scientific earthquake information from trusted international sources.

## Main Features

- Global earthquake monitoring.
- Interactive 2D and 3D Earth maps.
- Earthquake magnitude and depth information.
- Latest seismic events.
- Historical earthquake archive.
- Scientific reports and data visualization.
- Multilingual interface.
- User accounts and notifications.

## Scientific Data Sources

- USGS Earthquake Hazards Program.
- Other trusted international scientific institutions.

## Technologies

- HTML5
- CSS3
- JavaScript
- Leaflet Maps
- Node.js (planned)

## Project Status

Currently under development.

## Mission

Making global seismic information accessible to everyone through a free scientific platform.
